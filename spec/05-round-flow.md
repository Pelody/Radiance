# 回合流程、Action Set、Refresh 與勝負

這個模組是「議程」：依序呼叫各階段，並負責 Action Set 與 Refresh 兩個階段本身。其他階段的細節在各自的模組。

## 回合流程 [p.42–43]

每回合依序進行 8 個階段，Refresh 結束後若未分勝負，開始下一回合：

`P1 Staging → P2 Action Set → P3 Engagement → P4 Darkness → P5 Explore → P6 Attack → P7 Defend → P8 Refresh`

勝負條件隨時檢查 (本檔最後)，失敗條件一旦成立**立即**結束遊戲。

各階段所在的模組：P1、P3、P6、P7 → `07-enemies-and-combat.md`；P4 與 Treachery → `08-darkness-and-treachery.md`；P5 與移動 → `09-world-and-travel.md`；P2、P8 在本檔。行動窗口見 `03-effect-engine.md` EE-17、EE-18。

## P2 Action Set Phase [p.46–47]

- **P2-01** 從手牌打出 **3 張**，各放到不同卡槽：
  1. **行動卡** (`action`)：本回合可使用其效果 (KC-11)。
  2. **攻擊卡** (`attack`)：提供 AP 與本回合主攻擊類型 (`attack_type`)。
  3. **加成卡** (`booster`)：其 `element` 成為本回合 `activeElement` (決定哪些技能啟動，以及哪些永久加成卡啟動)，並提供 `attack_booster` 與 `explore_booster`。
- **P2-02** 第 4 張是**探索卡**：上回合的攻擊卡 (第一回合為開局放的那張)。不需支付光費。
- **P2-03** 光減少「3 張打出卡的光費總和 + 費用修正 (例如 Treachery legacy)」。
- **P2-04** **必須**打出 3 張，不能少打。
- **P2-05** 失敗條件：手牌中**最便宜的 3 張**的光費總和 > 目前的光，立即失敗 [p.42 明寫]。只要付得起，引擎只允許玩家選擇付得起的組合 (p.47「選了付不起的卡就失敗」不讓玩家誤觸)。光費包含費用修正 (例如 Treachery legacy)。手牌不足 3 張的情況見 OPEN-02。

## P8 Refresh Phase [p.64–65]

- **P8-01 更新地點**：若 New Location 指示物在目前地點上，把它移到地點牌庫頂端 (`newLocationTokenOnLocation = false`)；否則在目前地點放 1 個 `ThreatToken`。
- **P8-02 產光**：光軌道 + 目前光產出值 (KC-08)。光軌道上限見資料表 D-01。
- **P8-03 休息 (可選，兩種可都做)**：
  1. **物理休息**：支付 3 XP，移除最多「目前 Rest 值」個傷害。
  2. **光子休息**：棄掉任意數量的信標，每個治療 2，並在地點放 1 個 `Obstacle`。
- **P8-04 棄牌與移位**：把行動卡、加成卡、探索卡依**玩家選擇的順序**放入棄牌堆 (會影響 echo)。攻擊卡移到探索卡槽，作為下回合的探索卡。然後可選擇再棄掉任意張手牌 (必須在棄掉行動組之後)。
  - 此後加成卡已棄掉，技能不再啟動；KC-18 的「橫置以啟動」也在此結束。
- **P8-05 補牌**：抽牌補到目前手牌上限 (KC-08)，需要時依 KC-27 重洗。
- **P8-06 夥伴 Ready**：若有夥伴且已橫置，轉回直立 (CO-07)。
- **P8-07** 回合結束：檢查勝利條件 (WIN-01)，然後開始新回合。

## 勝負 [p.42, p.67–68]

- **LOSE-01** 以下任一條件成立時，**立即失敗**：
  1. 角色傷害 ≥ HP (KC-22)；
  2. 腐化達到 Shade 卡上的腐化上限；
  3. 已完成 Treachery 數達到 Shade 卡上的上限 (TR-01)；
  4. Action Set Phase 付不起光費 (P2-05)；
  5. 選用規則加上的失敗條件：強制支線任務 (SQ-10)、強制 Location Baron (LB-09)、限定任務的條件 (LQ-03)、Twin Flames 任一玩家失敗 (TF-13)。
- **WIN-01** 勝利需同時滿足：
  1. Shade 已被擊敗 (傷害 ≥ Shade 的 HP)；
  2. 目前所在的最終地點已探索 (FL-01)；
  3. 兩個條件都達成後，**撐到該回合結束**。
  - 兩個條件不需要在同一回合達成，順序不拘。Shade 被擊敗後移出遊戲，繼續遊戲直到其他條件達成。
  - Shade 卡的背面可能有額外的勝利條件或特殊規則，以該卡為準。
  - ⚠ INTERP：在 P8 結束時檢查。若最終地點在回合中因 EV 上升而恢復未探索狀態 (FL-03)，則不算達成。
