# 夥伴 (選用)

## 夥伴 (CO) [p.76–77]

夥伴是幫你作戰的盟友，用難度評分換取幫助 (`04-setup-and-difficulty.md` 難度)。卡片資料：`cards.json` 的 `companion` (8 張 × 基礎/進階兩面)，欄位 `attack`、`attack_type`、`defense`、`explore`、`strength` (強度 1–3)、`hp`、`effects`。

- **CO-01 開局**：選定的夥伴以**基礎面**、直立 (Ready) 放置。最多 3 個 (`04-setup-and-difficulty.md` 難度)。夥伴「開局時」的 Passive (Silva、Valence) 依 SU-22 結算。
- **CO-02 橫置的四種用途**：Ready 的夥伴可以橫置 (轉 90 度)，用於以下其中一種，每回合最多一次 (因為橫置後要到 P8 才恢復)：
  1. **探索**：在 Action Set Phase，把夥伴的 `explore` 加到探索卡的探索值上。視為「探索卡的探索值增加」(會影響參照探索卡數值的效果)。
  2. **攻擊**：在 Attack Phase，用夥伴的 `attack` 與 `attack_type` 攻擊玩家區的 **1 個**敵人。夥伴單獨攻擊，**不能**和你的 AP 合併。敵人的防禦類型與夥伴攻擊類型相同時，照常擋下。擊敗的敵人照常給 XP 與結算 When Defeated。 雙重類型的敵人一律擋 (P6-02)。
  3. **防禦**：在 Defend Phase，讓夥伴成為**某一次**敵人攻擊的唯一目標。不能讓夥伴和角色分攤防禦或傷害。夥伴的 `defense` 在類型相符時擋下傷害，剩下的傷害變成**夥伴身上**的傷害。 敵人是雙重類型時，夥伴的防禦一律適用 (P7-01a)。
  4. **Exhaust 能力** (`effects` 中 type = `Exhaust`)：每回合一次，橫置夥伴後結算。有階段限制的 (例：「Refresh Phase: …」) 只能在該階段使用。
  - ⚠ INTERP：夥伴的攻擊**不算**「你的攻擊」，參照攻擊卡、主攻擊值或「you attack」的效果不適用於夥伴攻擊，除非文字特別提到夥伴。見 OPEN-17。
- **CO-03 夥伴陣亡**：夥伴身上的傷害 ≥ 其 `hp` 時被擊敗，**移出遊戲**。
- **CO-04 Passive 能力**：只要夥伴在場就生效，**橫置時也有效**。
- **CO-05 Destroy 能力**：夥伴**橫置時也能使用**。結算完後夥伴被擊敗、移出遊戲。
- **CO-06 翻面 (Flip)**：基礎面有翻面條件。條件**一成立就立即**翻到進階面，之後整局保持進階面。翻面時若是橫置狀態，翻面後仍然橫置。條件在遊戲動作 (例：重洗) 中成立時，在該動作完成後翻面 (EE-11)。
  - ⚠ INTERP：翻面時身上的傷害保留。
  - ⚠ INTERP：Meldikar 的翻面條件是「When Meldikar is destroyed」，解讀為它被擊敗時改為翻面、不移出遊戲 (取代效果，EE-03)，翻面後傷害歸零。若照字面「被擊敗後才翻面」，它已移出遊戲，翻面就沒有意義。
- **CO-07 恢復**：每回合 P8-06，橫置的夥伴轉回直立。
- **CO-08 治療**：「Heal X」一律治療**角色** (KC-26)。夥伴只能被明確寫到它的效果治療。
