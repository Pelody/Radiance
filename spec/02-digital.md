# 數位化原則 (共用)

這是電子版，不是桌遊模擬器。規則書裡推方塊、翻墊子、查表、擺指示物，是紙本記錄狀態的方式；電子版只需要記住數字，把數字的意義直接顯示出來。打個比方：桌遊像手寫記帳本，電子版像試算表，帳目規則一樣，但加總和結餘由系統自動算好。

### 規則不變，操作自動

- **DG-01 規則不變**：背後的計算必須和規則書**完全一致**，只是不讓玩家看到操作過程。查表數值一律來自 `data/tracks.json`。不可以為了實作方便而簡化規則。例：距離方塊只在**移動結束時**重設到腐化對應的框；兩次移動之間腐化上升，方塊並不會跟著移動 (OPEN-18)。所以程式要記住方塊位置，不能每次都從目前腐化值推算。
- **DG-02 自動執行**：不需要玩家選擇的步驟一律自動執行，並寫入日誌讓玩家可以回看。例如：Staging 翻敵人、P3 接戰、產光、補牌、重洗與腐化 +1、距離結算與軌道推進、抵達時清除指示物、Treachery 完成流程、強制效果 (只有一種結算方式時)。
- **DG-03 停下來問**：需要玩家選擇的地方才停 (`90-open-items.md` 的玩家決策點)。只有一個合法選項時直接執行 (EE-24)。
- **DG-04 條文用語**：本規格保留「方塊前進」「翻面」等實體描述，是為了和規則書對照查證。實作時一律依下表轉換成狀態，**不要在程式中模擬實體物件**。

### 實體操作與內部狀態對照

- **DG-05**

| 規則書的實體操作 | 電子版的狀態 (`01-state-and-data.md`) | 玩家看到的 |
|---|---|---|
| 腐化方塊 | `corruption` (整數) | 腐化值 / 上限，以及下一級的影響 (DG-07) |
| 距離方塊、前進、重設到腐化下方 | `distanceBox` (框的編號)。移動時 `distanceBox + 距離` 查表得推進量，移動結束後 `distanceBox = 腐化值對應的框` | 移動前的代價預覽 |
| 威脅、抗性方塊 | `threat`、`resistance` (格子位置) | 目前威脅值、抗性值 (區段值)，以及離下一區段還差幾格 |
| 光軌道方塊 | `light` | 光、目前接戰數、離下一個接戰區段還差多少 |
| 兩條成長軌道方塊 | `abilityGrowthPos`、`characterGrowthPos` | 目前數值、下一格的費用與效益 |
| Shade 影響墊方塊 | `shadeInfluence` | 已探索地點數、若現在揭示 Shade 會得到的效果 |
| 任務板方塊 | `questBoard.pos` | 下一個任務的費用 |
| 技能方塊 (元素、Ready / x 面、在鎖頭或解鎖位置) | 每個技能的 `cubeElement`、`exhausted`、`unlocked` | 技能可不可用，不可用時顯示原因 |
| New Location 指示物在地點上 / 在牌庫頂端 | `newLocationTokenOnLocation` | 不需顯示，直接反映在 P8 是否加威脅 |
| New Location 指示物翻到 Fetch: Exhausted | `fetchReady` | Fetch 是否還能用、目前地點是否符合條件 |
| 信標墊 Ready / Exhausted | `beaconMatReady` | 搜尋行動是否可用 |
| 指示物 (Progress、Wound、Threat、Path、Obstacle、XP) | 各處的計數器 | 數字。沒有數量上限 (SU-20) |
| 夥伴、最終地點橫置 | `exhausted`、`explored` 旗標 | 狀態標示 |
| 塞在 Baron 下面的記號卡 | `isBaron` 旗標 | 標示哪些敵人是 Baron |
| 已完成 Treachery 疊在下方露出 legacy | `completedTreacheries` 列表 | 生效中的 legacy 清單 |
| 規則書建議的「暫時棄牌堆」(p.33，用來記 echo) | Echo 快照 (EE-14) | 結算中顯示快照的 echo |
| 洗牌 | 可設定種子的亂數 (EE-25) | 無 |

### 畫面預覽

桌遊要玩家自己心算的東西，電子版直接算好給玩家看。這是電子版最大的價值。

- **DG-06 常駐狀態列**：HP 與傷害、光 (含接戰數與下一個區段門檻)、XP、腐化 / 上限、威脅值、抗性值、Treachery 進度 / PV、已完成 Treachery / 上限、已探索地點數、牌庫與棄牌堆張數、echo、手牌上限、光產出、休息值、信標數 / 上限。
- **DG-07 腐化預覽**：顯示「再 +1 腐化」會造成的變化：離失敗還差幾級、場上參照腐化的效果 (例：Green Wraith 的攻擊、Shadow 的干擾效果) 會變成多少，以及下次移動結束後的新起點 (依 OPEN-18，影響的是再下一次的移動)。
- **DG-08 Action Set 預覽**：選卡時即時顯示光費總和、付完後的光與**接戰數變化**、本回合 AP 與 EP、啟動元素，以及因此會啟動哪些技能與永久加成卡。付不起的組合不能選 (P2-05)。
- **DG-09 Darkness 預覽**：分配 EP 時即時顯示 Treachery 會增加多少進度、會不會因此完成 (以及它的 When Completed 與 legacy 內容)、地點會不會探索完成、剩餘 EP 會去哪裡。
- **DG-10 移動預覽**：每一個候選目的地 (信標、剛翻開的地點、Fetch 的選擇) 都顯示距離明細 (地理距離、障礙、道路、延後數、效果修正)、威脅與抗性推進量、是否溢出產生威脅指示物、新地點會帶多少威脅指示物 (T3b)。延後一張地點時，顯示它對距離的影響。緊急信標顯示兩種付費方式的代價。
- **DG-11 Attack 預覽**：分配 AP 給敵人時，顯示會被擋下多少、擊敗需要多少、分配後剩多少 AP。
- **DG-12 Defend 預覽**：每次攻擊顯示攻擊值與類型、手牌中可以拿來防禦的卡、預計受到的傷害。
- **DG-13 Refresh 預覽**：休息的效果、補牌是否會觸發重洗 (腐化 +1) 的警告。
- **DG-14 成長預覽**：兩條軌道下一格的費用與效益；目前不能成長時 (KC-06) 顯示原因。
- **DG-15 失敗警告**：任何會直接導致失敗的選擇，先要求確認。
- **DG-16 可用性說明**：每張卡、每個技能在目前狀態下能不能用，不能用時說明原因 (例：「技能未啟動：需要 Earth 加成卡」、「此效果不在行動卡上」)。

### 預覽的界線

- **DG-17 不洩漏隱藏資訊**：電子版只幫玩家「算」，不給玩家紙本拿不到的資訊。不可以顯示：玩家牌庫順序、敵人牌庫頂端、地點牌庫中未翻開的卡、Treachery 牌庫順序。效果允許查看時例外 (例：Scout、夥伴 Meldikar「地點牌庫頂端朝上」、P7-02 的防禦查看)。
- **DG-18 預覽要可靠**：預覽必須用和實際結算**同一套**計算程式產生，不另外寫一份估算邏輯。若某個結果取決於尚未發生的玩家選擇或隨機翻牌，預覽要標明「不含 …」，不可以假裝確定。
