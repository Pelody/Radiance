# 介面 (UI)

本檔記錄 Paul 決定的介面方向。規則怎麼算看其他檔；這裡只管「怎麼呈現、怎麼操作」。版面細節以設計稿為準：`design/main-screen.html` (可直接用瀏覽器打開的靜態稿) 與 `design/main-screen.png` (截圖)。設計稿呈現官方 Example Turn Guide 第 1 回合 Action Set 的狀態，Paul 已確認 (1.5)。設計稿用到的卡圖與彩色圖示在 `design/assets/`；正式實作請用 `data/icons/` (currentColor 版) 與卡片資料切圖。

## Paul 的決定 (1.4.3)

- **UI-01 平台**：電腦瀏覽器。單一網頁，不需要伺服器，遊戲狀態存在瀏覽器裡。
- **UI-02 復原**：翻開新資訊**之前**的決定都可以復原 (例：選錯卡、AP 分錯)。翻開敵人、地點、Treachery，抽牌、洗牌之後，不能復原到那之前，以免等於偷看 (DG-17)。
- **UI-03 節奏**：自動步驟以短動畫快速播放，並寫入日誌 (DG-02)。重要事件停下來讓玩家看清楚再繼續：Treachery 完成、腐化上升、地點探索完成、敵人擊敗、Shade 進場、失敗或勝利。
- **UI-04 卡片外觀**：使用 PnP 卡圖 (依 `data/cards.json` 的 `page`、`row`、`col` 從 9-up PDF 切出)。滑鼠移到卡上時放大。傷害、進度等指示物以數字標記疊在卡上。

- **UI-04a 遊戲名詞用官方英文** (Paul 要求)：畫面上凡是遊戲的專有名詞，一律用卡片與規則書上的官方英文，不自行翻譯。例：Action、Attack、Explore、Booster、Companion、Hobby Market、Quest Area、Player Area、Beacons、Light、Corruption、Threat、Resistance、Engagement、Progress、Obstacle、Path、Threat token、Final Location、Shade Influence、Reveal、Wounds、Hand Size、Rest、元素 Earth / Fire / Wind (方塊上寫 E / F / W)，階段名稱 Staging、Action Set、Engagement、Darkness、Explore、Attack、Defend、Refresh。說明句子、按鈕 (確認、重選、復原) 與電子版自己加的區塊名稱 (世界、地圖、日誌、輪到你) 用中文。
  - 註：規格本文 (spec/) 仍以中文說明規則，名詞對照見 `01-state-and-data.md` 的術語表 (KC-30)；實作畫面時以本條為準。

- **UI-04b 圖示優先** (Paul 要求)：有官方圖示的名詞一律用圖示，不寫文字 (例：Physical、Light、Progress、Threat、XP、元素)。圖示取自規則書內嵌的 Radiance 圖示字型，已轉成 `data/icons/<名稱>.svg` (64 個，`fill="currentColor"`，可用 CSS 換色)。滑鼠移上去顯示名稱。數值一律放在「圖示 + 數字」的小方塊裡，不寫成句子。
- **UI-04c 簡約、不換行** (Paul 要求)：畫面要簡約、有質感、一目了然。標籤、數值、按鈕文字不可以斷成兩行；放不下時要調整版面或縮短文字，而不是讓它換行。日誌這類長文字改用單行加省略號，滑鼠移上去看全文。對齊：每條軌道上方的圖示與數值置中在該軌道正上方；「輪到你」列的數值小方塊整組置中；世界區與右上角狀態區的小方塊內容靠左。

## 主畫面配置

- **UI-05** 上方：回合數、8 個階段的進度列、復原與選單 (成長、設定)。
- **UI-05a 主畫面配置** (Paul 確認的版面，參考規則書 p.12–15、p.46–47 與官方遊戲墊)：
  - 左 = 世界：目前地點 (標「新地點」指示物、Fetch 是否可用)、信標格與搜尋是否可用、地圖、Shade 影響墊；下方是日誌。
  - **地圖** (Paul 決定照紙本)：顯示玩家目前位置、走過的地點 (依移動順序連線)，並標出 Shade 卡上**所有**最終地點候選 (SH-01、SH-02；例：Greed 有 3 個)。走到其中一個後，那一個成為本局最終地點，其餘候選取消標示。被開局規則移出遊戲的座標 (例：Greed 移出座標含 6 的地點) 以虛線格顯示。
  - 中上 = 任務區 (右邊是前端)，最右邊是進行中的 Treachery。任務區與玩家區的敵人排成一列**置中**：第一張在正中間，之後依規則往左 (後端) 或往右 (前端) 加，整列保持置中 (Paul 要求)。
  - 中間 = 玩家區，接著是「輪到你」決定列 (預覽數值與確認按鈕)。
  - 中下 = 玩家板：**行動卡**在角色墊左邊，角色墊 + 職業墊用 PnP 墊子圖片並排，**加成卡**在職業墊右邊，再往右是**夥伴**。墊子下方：Attack 位置放**攻擊卡**、Explore 位置放**探索卡**。加成卡與夥伴的下方是**嗜好市場** (2 張可招募的牌)。已裝備的永久加成排在加成卡旁。手牌貼齊最下方、與玩家板置中對齊 (「手牌」標籤放在左下角，不影響置中)。
  - 右 = HP、XP 與直式軌道 (UI-06b)，以及其他數值 (完成 Treachery、已探索、手牌上限、光產出、休息值、牌庫 / 棄牌張數)。
  - **卡槽名稱** (Paul 要求)：行動卡、攻擊卡、探索卡、加成卡、夥伴等卡槽空著時，名稱寫在格子正中間；卡片放上去就蓋住，不另外加標籤。角色墊、職業墊上已印名字，不再另外標示。
  - **不畫牌堆** (Paul 要求)：牌庫、棄牌堆、敵人牌庫、地點牌庫、Treachery 牌庫、永久加成牌庫、嗜好牌庫都不畫成卡堆。玩家需要的張數 (自己的牌庫、棄牌堆) 以數字顯示在右側。
  - **比例**：卡片與墊子依實物比例 (卡片 180×252 pt、墊子 505×318 pt)，所有卡片同一個大小。
  - **對齊**：行動卡、加成卡、夥伴與墊子**上緣對齊** (照實體擺法)。
  - 技能直接畫在墊子上：每個技能疊上元素方塊 (顏色加字：火、土、風)，未解鎖的技能蓋一層暗色，目前可以用的技能 (已解鎖、Ready、元素符合) 加金框與「可用」標記 (DG-16)。
- **UI-06** 常駐狀態 (DG-06) 分散放在對應的實體位置；其餘數值放在右側軌道下方。
- **UI-06b 實體軌道一律畫成直式軌道** (Paul 要求)：桌遊上是軌道的數值，電子版也畫成完整的直式軌道，不只顯示數字。方向統一為「越往下越糟」。右側並排光、腐化、威脅、抗性四條 (資料：`data/tracks.json`)：
  - **畫法要簡潔** (Paul 要求)：目前位置只用「亮起來」表示，不另外加點、箭頭等符號；數字只標區段值，不逐格標號。左側世界欄與右側軌道欄同寬 (300)，左右對稱；四條軌道在軌道欄內水平置中。
  - 光：上 20 → 下 0，依 `light_track.engagement` 分段，每段只寫接戰數；該段還會多翻敵人時寫成「4+」。目前所在的段亮起來；Action Set 預覽「付完光之後」的值寫在標題旁 (例：20 → 16)，跨到別段時那一段加外框。
  - 威脅、抗性：上 0 → 下 27，依 `value` 分段，每段只寫區段值；目前所在的段亮起來，標題下寫「差 N 格」。
  - 腐化：見 UI-06a。
  - Shade 影響墊放在左側世界區：12 格由上往下，每格標「抵達次數」與現身時的效果 (威脅 +X 或 XP +X，D-05、SH-03)。
  - 成長軌道放在「成長」畫面 (另外設計)。
- **UI-06a 直式腐化軌道** (Paul 要求)：軌道區放完整的腐化軌道，由上 (1) 往下 (20)。每一列是一個腐化值；旁邊依 `data/tracks.json` 的 `distance_track.boxes` 畫出距離框 (一框跨它對應的腐化值)，排法為「威脅 | 腐化值 | 抗性」三欄：腐化值在中間一欄 (軌道標題置中在它正上方)，左右兩欄是距離框的威脅、抗性推進量，欄位上方各放一次 Threat、Resistance 圖示。目前腐化值用金底、距離方塊所在的框 (`distanceBox`，依 OPEN-18 不一定在腐化那一列) 用金框、Shade 的腐化上限用紅底；超過上限的腐化值淡化，但距離框不淡化，因為移動時仍可能走到。
- **UI-07** (已由 UI-05a 取代)
- **UI-08** 「輪到你」決定列放在玩家區與玩家板之間，DG-08 ~ DG-14 的預覽都顯示在這裡。預覽數值用一格一格的小方塊呈現，**即時更新**：玩家每改一個選擇，數字直接變成結果值；比選擇前變高顯示綠色、變低顯示紅色、不變維持原色。不寫「A → B」或「−4」之類的說明文字 (Paul 要求)。日誌在左下，每行標規則編號，點擊顯示該規則的白話說明。
- **UI-08a** 畫面以 1600×1000 設計，實際依視窗大小等比例縮放。
- **UI-09** 即將發生的結果直接標在牌桌上 (例：Action Set 時，將接戰的敵人標上「將接戰」)，與預覽面板使用同一套計算 (DG-18)。

## 行動窗口的節奏 (1.5.3，Paul 決定)

- **UI-10 遇到要選擇的才停**：引擎依 EE-17 在每個行動窗口都提供選項；畫面預設**自動繼續**，只在下列情況停下來：
  1. 非窗口的決策 (選卡、分配 EP、選目的地、防禦用卡、棄牌順序、效果的選項……)；
  2. 窗口裡有該階段本身的選擇 (Attack 分配 AP、Defend 選下一個攻擊的敵人)；
  3. 窗口裡有可用的卡片、技能、地點或敵人效果，而且本回合還沒在停下時略過它；只能在本階段使用的效果 (「Phase 名稱:」) 每個階段都會停。
  - 成長、搜尋、橫置以啟動、技能第二次使用、非玩家的階段強制效果 (EE-18a) 不會讓畫面停下；停下時可以用。
  - 免費光 (EE-23) 這類只有好處的效果自動使用並寫入日誌。
  - 設定裡有「每個窗口都停」開關。
  - 復原時跳過自動繼續的窗口，回到上一個停下來的地方。
