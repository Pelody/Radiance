# Blitz 快速模式 (選用)

## Blitz 快速模式 (BZ) [p.80–81]

- **BZ-01** 不選 Shade。改選 1 個 Shadow 當最終對手。
- **BZ-02** 該 Shadow 開局以干擾面放置，干擾效果從開局就生效，照 Intervene 條件介入 (`12-shadows.md`)。
- **BZ-03 失敗上限**：腐化上限與已完成 Treachery 上限，為對應 Shade 卡數值的一半，**無條件進位**：

| Shadow | 對應 Shade (腐化 / Treachery) | Blitz 上限 (腐化 / Treachery) |
|---|---|---|
| Greedling | Greed (5 / 3) | 3 / 2 |
| Vanity Wisps | Pride (10 / 4) | 5 / 2 |
| Covetous Flail | Envy (9 / 6) | 5 / 3 |
| Ravager | Wrath (12 / 3) | 6 / 2 |
- **BZ-04** Shadow 進場的那一回合結算 Shade 影響墊 (SH-03)，但數值**減半、無條件進位**。
- **BZ-05** Shadow 進場時你所在的地點成為**最終地點**，適用 FL-01 ~ FL-04。
- **BZ-06** Fetch 除了 T1a 的條件外，還需要**已探索至少 3 個地點** (以 Shade 影響墊位置判斷)。
- **BZ-07 勝利**：擊敗該 Shadow + 探索最終地點，並撐到該回合結束 (同 WIN-01)。
- **BZ-08** Ravager 被擊敗一次後就不再復活。
