# 世界：探索、移動與信標

## 信標與搜尋 [p.38–39]

- **KC-28** 信標 = 移動時保存的地點卡 (T1c)，數量上限 = luminary 墊上的 `beacon_limit`。花費或棄掉的信標一律進入**地點棄牌堆**。
- **KC-29** 信標的用途：
  1. **搜尋行動**：每個地點限 1 次，除了移動過程中以外，任何時候都能做。信標墊從 Ready 翻到 Exhausted，在目前地點放上**等於目前信標數量**的 `Path`。沒有信標時也可以搜尋 (放 0 個 Path，信標墊照樣翻面)；p.38 沒有數量要求 (1.5.2)。抵達新地點時信標墊翻回 Ready。
  2. **光子休息** (P8-03)：每棄 1 個信標治療 2，並在地點上放 1 個 `Obstacle`。
  3. **探索加成** (P4-01)：每棄 1 個信標，探索加成 +2，並在地點上放 1 個 `Obstacle`。
  - 其他效果要求花費或棄掉信標時，**不放** `Obstacle`。只有用途 2 和 3 會放。

## P5 Explore Phase [p.54–60]

- **P5-01** 每 1 點剩餘 EP，在目前地點放 1 個 `Progress`。
- **P5-02** 地點的探索值 `EV = 卡片 explore_value + 抗性軌道目前區段值 (資料表 D-04) + 效果修正`。(最終地點另見 FL-01。)
- **P5-03** 進度 < EV → 進入 P6。
- **P5-04** 進度 ≥ EV → 地點**已探索**：獲得地點的 `xp_reward`，然後**立即移動** (P5-T)。例外：最終地點不移動也不給 XP，見 FL-02。
  - 探索完成後到移動之前，**不能**使用卡片行動或技能。
  - 多出來的進度**不會**帶到下一個地點 (與 Treachery 不同)。
- **P5-05 臨時移動**：任何時候 (不限 Explore Phase) 因放置進度使地點被完全探索，立即依 P5-T 移動，完成後回到原本的流程位置。

## 移動 (P5-T) [p.55–60]

**T1 選擇目的地**，三種方式擇一：
- **T1a Fetch** (每局限 1 次)：條件為 `fetchReady` 為真，且**剛探索完的地點座標 east + south ≥ 6**。翻面 New Location 指示物 (`fetchReady = false`)，支付 4 XP，從地點牌庫中任選 1 張作為目的地。此方式**不能**保存信標或延後地點，但目前地點上的 Path/Obstacle 照常計入距離。
- **T1b 前往信標**：選 1 個已保存的信標作為目的地 (從信標中移除)。
- **T1c 尋找目的地**：從地點牌庫逐張翻開，每翻 1 張就選擇：
  1. **前往**：以此地點為目的地，進入 T2。
  2. **保存為信標**：僅限信標數 < `beacon_limit` 時。繼續翻下一張。
  3. **延後**：暫放一旁，本次移動距離 +1，移動結束時放回地點牌庫底部 (T3d)。不佔信標容量，數量不限。繼續翻下一張。
  4. **緊急信標移動**：先把這張翻開的地點保存為信標或延後 (參考卡只寫「延後」，規則書 p.57 寫「保存或延後」，依規則書)；然後選擇支付 3 XP 或威脅軌道 +2 (XP 不足 3 時只能選威脅)；最後選 1 個已保存的信標作為目的地，進入 T2。
**T2 結算距離**：
- **T2a** `distance = |Δeast| + |Δsouth| + 目前地點上的 Obstacle 數 − Path 數 + 延後地點數 + 效果修正`，**最小值為 1**。依據：參考卡「Resolve Distance (minimum of 1)」；夥伴 Silva 的「減少距離 (最低 1)」也一致。(原 OPEN-04 預設為 0，是錯的，已修正。)
  - 卡片明寫不同下限時，以卡片為準 (EE-02)。例：Wayfarer 進階 Foresight「每棄 1 信標距離 −2 (最低 0)」，使用它時距離可以降到 0。⚠ INTERP：規則書沒有說明兩者衝突時的優先順序，依「卡片文字優先於一般規則」的通則。
- **T2b** 距離軌道的格子是腐化軌道下方的**框** (不是腐化軌道的數字)。方塊從目前的框前進 `distance` 個框，依**到達的框**上標示的數值推進威脅軌道與抗性軌道 (資料表 D-02)。然後把距離方塊**重設到腐化方塊下方對應的框** (腐化越高，起點越右邊)。重設只在這個時候發生；之後腐化上升，方塊不會跟著移動，見 OPEN-18。開局時方塊在最左邊的框 (SU-09)，High Radiance 開局腐化 +1 時也一樣，見 OPEN-18。
- **T2c** 若方塊已到距離軌道最右框仍需前進，每多 1 點距離，在**目的地**放 2 個 `ThreatToken` (困難面為 3 個)。
**T3 抵達目的地** (依序)：
- **T3a** 棄掉已探索地點上的 ThreatToken 與 Progress；附著卡棄到玩家棄牌堆 (KC-17)。已探索地點進入地點棄牌堆。目的地成為目前地點，New Location 指示物放在上面 (`newLocationTokenOnLocation = true`)。
- **T3b** 舊地點上每 **2 個** `Path`，在新地點放 1 個 `ThreatToken` (無條件捨去)。然後棄掉舊地點的所有 Path 與 Obstacle。
- **T3c** 信標墊翻回 Ready (`beaconMatReady = true`)。
- **T3d** 延後的地點放到地點牌庫底部。
**T4** 若**出發的地點已完全探索**，Shade 影響軌道 +1 (= 已探索地點數的可靠計數) [p.60；條件出自參考卡]。由效果引起、出發地點未探索完的移動，不前進。
**T5** 結算新地點的 Upon Arrival 效果，以及新舊地點上「移動後 / 離開時」的效果。若目的地是 Shade 的最終地點，記錄下來以進行 SH-02 揭示。
