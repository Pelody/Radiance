# 角色：成長、技能、牌組與傷害

## 成長 [p.23–26]

- **KC-05** 成長：支付成長軌道上「目前方塊右邊下一格」標示的 XP，方塊前進一格，獲得該格效益。兩條軌道：能力成長、角色成長。
- **KC-06** 幾乎任何時候都可以成長，但以下情況不行：
  1. 正在結算某個效果的過程中；
  2. Attack Phase 中正在把 AP 分配給敵人的過程中；
  3. Defend Phase 中正在結算敵人攻擊的過程中。
- **KC-07 能力成長軌道**：前進到新格時，**立即結算一次**該格效益：
  - `Recruit` N：重複 N 次 KC-30 的 Recruit。
  - `Upgrade` N：從**手牌**選 N 張基礎面卡翻到進階面，之後永久保持進階面。進階面效果更強，光費也更高。
  - `Unlocked` N：**逐一**解鎖 N 個技能 (KC-13)，後解鎖的可以用先解鎖的當相鄰依據 [p.24]。
- **KC-08 角色成長軌道**：`HandSize`、`Light` (光產出)、`Rest` 三種數值，**目前值 = 方塊位置以下 (含) 及其左邊出現過的最大值**。
  - `HandSize` X：Refresh Phase 補牌到 X 張。
  - `Light` X：Refresh Phase 光軌道 +X。
  - `Rest` X：物理休息時最多移除 X 個傷害。
  - `+1 PermBooster`：**立即**從永久加成來源牌庫選 1 張卡裝備 (放在職業墊右側，基礎面)。必須立即支付：**該卡光費 + 所有已裝備、且元素與該卡相同的永久加成卡的光費總和**。
    - ⚠ INTERP：規則書沒說付不起時怎麼辦。只能選付得起的卡；來源牌庫中沒有任何一張付得起時，不能前進到這一格 (XP 也不扣)。
- **KC-09 永久加成卡**：
  - 一律基礎面，整局保留。
  - **不提供特質**，也不提供卡片效果，只提供加成數值。
  - 當其元素 = 本回合加成卡的元素時「啟動」，提供其 `attack_booster` 與 `explore_booster` (見 P2、P4、P6)。

## 技能 [p.34–35]

- **KC-13 解鎖**：只能解鎖與**已解鎖技能正交相鄰**的技能。例外：
  1. luminary 墊最左欄的 2 個技能互相視為相鄰；且各自與第二欄中**離它最近的 2 個技能**相鄰。
  2. profession 墊最右邊的技能與其左側欄的 **3 個技能**都相鄰。
  - 版面 (`skills[].column` 與順序)：luminary 第 0 欄 2 個、第 1 欄 3 個；profession 第 0 欄 3 個、第 1 欄 3 個、第 2 欄 1 個。
  - 依規則 1，luminary 第 0 欄上方技能與第 1 欄的第 1、2 個相鄰，下方技能與第 1 欄的第 2、3 個相鄰。
  - **跨墊相鄰**：兩張墊子緊鄰擺放、luminary 在左 [p.14]，因此 **luminary 第 1 欄第 r 個技能與 profession 第 0 欄第 r 個技能相鄰** (同一列)。依據：開局唯一解鎖的技能在 luminary 最左欄，若兩張墊不相連，除了 Wisdom 以外的角色永遠無法解鎖任何職業技能，這不可能是設計意圖。(原 OPEN-01，以此推導解決；規則書沒有逐字寫出列對列的對應，若實體墊子的技能列沒對齊，以實體為準。)
  - Wisdom 的特殊規則「開局免費解鎖職業墊最右邊的技能」之後，可從該技能解鎖其左側欄的 3 個技能 (例外第 2 條)。p.109 的說明「可以解鎖與任何已解鎖技能相鄰的技能」即指這個用法。
- **KC-18 使用條件**：技能必須**已解鎖 + Ready + 啟動中**才能使用。
  - **啟動中**：技能方塊的元素 = 本回合加成卡的元素 (`activeElement`)。
  - **橫置以啟動**：未啟動的技能可以橫置 (翻到有 x 的面) 來啟動它，效果持續到 **Refresh Phase 棄牌步驟 (P8-04)**。這是「必須 Ready」的唯一例外：該技能雖已橫置，本回合仍可使用。
  - **1x 技能第二次使用**：已解鎖、Ready、啟動中的 1x 技能，本回合可用 1 次；**橫置方塊**後可再用第 2 次。
  - **橫置狀態會延續到下一回合**。Refresh Phase 不會重置技能方塊；只有效果能讓技能重新 Ready。
- **KC-19 交換方塊** (Wisdom 的 Prep 技能)：交換兩顆方塊的位置，每顆方塊保留其 Ready/橫置狀態，技能保留其解鎖/鎖定狀態。

## 牌組：重洗與抽牌 [p.37–38]

- **KC-27** 牌庫為空、需要重洗時：**先腐化 +1**，再把棄牌堆洗成新牌庫 (卡片不翻面)。
- 會觸發重洗的情況 (前提都是牌庫已空)：
  1. Refresh Phase 補牌時還需要再抽；
  2. 效果要求抽牌時還需要再抽；
  3. Defend Phase 中，玩家**自願**重洗，以便用牌庫頂端的卡防禦；
  4. Mill 時牌庫用完 (見 KC-30)。
- **KC-27a** ⚠ INTERP：牌庫與棄牌堆**都是空的**時，無法重洗，也**不增加**腐化，剩下的抽牌或 Mill 直接略過 (見 OPEN-11)。

## 附著 [p.36]

- **KC-17** 把卡從手牌放到敵人或地點下方，露出文字框。敵人在兩區之間移動時附著卡跟著移動。地點被探索或敵人離場時，附著卡棄到**玩家的棄牌堆**。附著卡的特質算「在場」，不算「在行動組中」。

## 角色的傷害與治療 [p.36–37]

- **KC-22** 角色身上的傷害 ≥ luminary 墊印的 HP (`skill_mat.hp`)：**立即失敗**。
- **KC-24 直接傷害 (對自己)**：「deal yourself {Wound}」或「take {Wound}」不是敵人攻擊，**不可防禦**，直接放上傷害。
- **KC-26 治療**：「Heal X」= 從角色身上移除 X 個傷害。玩家的治療效果**不能**用在敵人身上。
